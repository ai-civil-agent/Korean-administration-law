2. 처분(행정행위)의 종류와 모습 "행정청이 내리는 결정의 생김새"

처분이 어떤 성격인지(기속/재량, 허가/특허/인가)에 따라 붙일 수 있는 조건, 법원이 심사하는 방법이 달라집니다.

★★★

허가 = 원래 자유인데 위험해서 잠시 막아뒀던 것을 풀어줌. 특허 = 원래 없던 새 권리를 특정인에게 만들어 줌. 인가 = 남들끼리 한 법률행위에 도장을 찍어 효력을 완성시켜 줌.

예시허가 = 운동장 자전거 타기 허락 / 특허 = 특정 학생에게 '매점 운영권'을 새로 줌 / 인가 = 학생들이 정한 동아리 규칙을 선생님이 승인해야 효력 발생
  • 허가: 운전면허, 건축허가, 일반음식점 영업허가 → 원칙 기속, 기존 업자의 이익은 반사적 이익
  • 특허: 귀화허가, 공유수면매립면허, 도로점용허가, 개인택시면허, 재개발·재건축 조합설립인가(이름은 인가지만 특허!) → 원칙 재량
  • 인가: 재단법인 정관변경 허가, 토지거래허가, 사립학교법인 임원 취임승인, 관리처분계획 인가

  • 부담 불이행 → 처분 철회 사유 / 부담 이행으로 맺은 증여계약 등은 부담과 별개의 법률행위

  2. 5)인가의 보충성 — 인가는 기본행위(정관변경 결의 등)의 효력을 '보충'할 뿐. 기본행위에 문제가 있으면 기본행위 자체를 민사소송 등으로 다퉈야 하고, 인가 자체에 고유한 하자가 있을 때만 인가처분을 다툰다.
